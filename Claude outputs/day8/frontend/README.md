# Parsimony frontend

React 18 + Vite + TypeScript, TanStack Router and Query, MUI.

    npm install
    npm run dev        # http://localhost:5173, /api is proxied to http://localhost:8000
    npm test
    npm run typecheck
    npm run build

Start the backend first (`docker compose up` from the repo root).
UI text is in `src/i18n/` (English, Korean, Uzbek). Colours and type come from `docs/design.md`.
